1. INTRODUCTION
--------------------------------------------------------------------------------
E-commerce has transformed the way businesses operate globally. With millions of
transactions happening daily, analyzing sales data has become critical for
business decision-making. This project focuses on analyzing e-commerce sales
data to extract meaningful insights about sales trends, customer behavior,
product performance, and regional distribution.

--------------------------------------------------------------------------------
2. PROBLEM STATEMENT
--------------------------------------------------------------------------------
Businesses generate large volumes of sales data but often lack the tools and
techniques to analyze it effectively. This project aims to analyze e-commerce
sales data to identify:
  - Which product categories generate the most revenue and profit
  - Monthly and seasonal sales trends
  - Regional performance differences
  - Impact of discounts on profitability
  - Most preferred payment modes by customers

--------------------------------------------------------------------------------
3. OBJECTIVES
--------------------------------------------------------------------------------
  1. To collect and preprocess e-commerce sales data
  2. To perform Exploratory Data Analysis (EDA) using Python
  3. To visualize key metrics using charts and graphs
  4. To build an interactive dashboard using Power BI
  5. To derive actionable business insights from the analysis

--------------------------------------------------------------------------------
4. SCOPE OF THE PROJECT
--------------------------------------------------------------------------------
  - Data covers orders from January 2024 to June 2024
  - Includes 60 transactions across 6 product categories
  - Covers 4 regions: North, South, East, West (India)
  - Analysis includes sales, profit, discount, and payment mode

--------------------------------------------------------------------------------
5. TECHNOLOGY STACK
--------------------------------------------------------------------------------
  Programming Language : Python 3.x
  Libraries Used       : Pandas, Matplotlib, Seaborn
  Visualization Tool   : Microsoft Power BI Desktop
  Data Format          : CSV (Comma Separated Values)
  IDE                  : VS Code / Jupyter Notebook

--------------------------------------------------------------------------------
6. METHODOLOGY
--------------------------------------------------------------------------------
  Phase 1 - Data Collection
    Prepared a structured dataset with 60 e-commerce sales records containing
    fields: Order ID, Date, Customer, Category, Region, Sales, Profit,
    Discount, Quantity, Payment Mode.

  Phase 2 - Data Preprocessing
    - Handled data types (date parsing, numeric fields)
    - Checked for missing values and duplicates
    - Created derived columns (Month, Profit Margin)

  Phase 3 - Exploratory Data Analysis (EDA)
    - Sales and Profit analysis by Category
    - Monthly Sales Trend analysis
    - Regional Sales Distribution
    - Top 10 Products by Revenue
    - Payment Mode Distribution
    - Discount vs Profit correlation

  Phase 4 - Visualization
    - Bar charts, Line charts, Pie charts, Scatter plots using Python
    - Interactive dashboard in Power BI

  Phase 5 - Insights and Conclusion
    - Derived business insights from analysis results

--------------------------------------------------------------------------------
7. EXPECTED OUTCOMES / KEY FINDINGS
--------------------------------------------------------------------------------
  1. Electronics category contributes the highest revenue (~60% of total sales)
  2. Maharashtra region dominates sales among all states
  3. Monthly sales show an upward trend from January to June 2024
  4. Higher discounts (>10%) negatively impact profit margins
  5. Online and EMI are the most preferred payment modes
  6. MacBook Air M2 and iPhone 14 are top revenue-generating products
